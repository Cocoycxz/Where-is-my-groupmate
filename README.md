# Where Is My Groupmate?

A responsive, front-end prototype for student group-project coordination.

## Run

Open `index.html` in a browser, then choose **Explore demo** or log in with any valid-looking email/password to enter the student workspace.

## Structure

- `student/` and `instructor/`: separate semantic HTML pages for each role.
- `css/`: reusable design tokens and responsibility-specific stylesheets.
- `js/`: modular behavior and centrally organized mock data in `data.js`.

## Prototype features

- Student and instructor dashboards
- Project, task, contribution, and peer-evaluation views
- Working task-creation modal and task filter
- Working confirmation-based Nudge interaction that updates the UI and notification data
